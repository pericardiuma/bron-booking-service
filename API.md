# Описание API

Базовый URL: `http://localhost:3000/api`
Защищенные маршруты требуют заголовок `Authorization: Bearer <token>`.

## Авторизация
* `POST /auth/login` — вход (передается `login` и `password`). Возвращает `accessToken`.

## Ресурсы
* `GET /resources` — список всех активных ресурсов.
* `GET /resources/:id` — информация о конкретном ресурсе.

## Бронирования
* `POST /bookings` — создание брони (требует заголовок `Idempotency-Key`).
* `GET /bookings/my` — список своих броней.
* `GET /bookings/:id` — просмотр своей брони.
* `POST /bookings/:id/cancel` — отмена своей брони.

## Административные маршруты
* `GET /admin/bookings` — все брони с фильтрами (только для админа).
* `POST /admin/resources` — создание ресурса (только для админа).
* `PATCH /admin/resources/:id` — изменение/отключение ресурса (только для админа).

## Коды ответов
* `200` — Успех
* `201` — Создано
* `400` — Ошибка валидации (неверное время, шаг и т.д.)
* `401` — Нет токена или он истек
* `403` — Нет прав (обычный юзер лезет в админку)
* `404` — Не найдено (или чужая бронь)
* `409` — Конфликт (время занято, дубликат ключа)
* `500` — Внутренняя ошибка сервера
