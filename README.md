# Бронь без конфликтов

## 1. Описание проекта
Веб-сервис для бронирования ресурсов образовательной организации. Позволяет пользователям бронировать аудитории, а администраторам — управлять ресурсами и просматривать аудит.

## 2. Технологический стек
* Backend: Node.js, Express
* База данных: PostgreSQL
* Frontend: HTML, CSS, JavaScript
* Тестирование: Postman
* CI/CD: GitHub Actions

## 3. Правила бронирования
* Рабочее время: ежедневно с 08:00 до 22:00 (МСК).
* Шаг времени: 30 минут.
* Длительность: от 30 минут до 4 часов.
* Нельзя бронировать в прошлом или более чем за 30 дней.
* Пересекающиеся активные бронирования одного ресурса запрещены.

## 4. Установка и запуск
1. Установите Node.js и PostgreSQL.
2. Склонируйте репозиторий.
3. Создайте файл `.env` на основе `.env.example` и укажите пароль от БД.
4. Выполните `npm install`.
5. Примените миграции: `npm run migrate`.
6. Создайте тестовых пользователей: `node scripts/seed-demo-users.js`.
7. Запустите сервер: `npm start`.
8. Приложение доступно по адресу: `http://localhost:3000`.
